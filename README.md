# P2P Analytics & Operations Optimizer

**Industrial Engineering | Data Analytics | Business Intelligence**

## About the Project

P2P Analytics & Operations Optimizer is an educational data analytics project focused on evaluating the profitability and operational efficiency of simulated peer-to-peer (P2P) cryptocurrency transactions involving USDT and Peruvian soles (PEN).

The project applies data analytics and industrial engineering principles to identify operational bottlenecks, analyze costs, measure performance, and evaluate process improvement opportunities.

## Objectives

- Analyze transaction profitability, costs, and trading volume.
- Measure transaction processing times and operational performance.
- Identify bottlenecks and opportunities for process improvement.
- Build analytical queries using SQL Server.
- Develop an interactive dashboard using Power BI.
- Evaluate operational improvement scenarios using simulated data.

## Technologies

- SQL Server
- Microsoft Power BI
- Python
- Microsoft Excel
- Git and GitHub

## Key Performance Indicators

- Net profit per transaction
- Net profit margin
- Trading volume
- Average transaction processing time
- Transaction completion rate
- Capital utilization
- Operational performance by time period

## Industrial Engineering Application

This project applies process analysis, time measurement, cost analysis, performance indicators, and continuous improvement to a simulated P2P trading process.

## Data Disclaimer

All initial data will be synthetic and created for educational purposes. The project does not guarantee profitability and is not an automated trading system or financial recommendation service.
